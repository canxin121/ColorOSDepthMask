## 验证边界

画板运行在 Android API 35 模拟器中的临时 instrumentation 应用内，使用实际 Android 绘图、触摸和输入服务。厂商矩阵读取真实 APK 的 DEX 与二进制 XML，在隔离进程中运行；UI 检查使用替代厂商控件，Hook 装配使用记录式后端。原生 parser、缓存和算法版本测试使用未经修改的厂商类。

原生 AI 检查验证接口和生命周期，不执行联网生成。全图填充耗时仅为本次模拟器观测，不代表真机性能。上述结果不等同于每个 ROM 的厂商服务、GPU、界面动画和实际锁屏验收；后续 Wallpapers 或 ROM 改变内部行为时仍可能需要适配。

## 更新与复测

覆盖安装后重载 Wallpapers，重新打开壁纸预览。普通壁纸可直接编辑蒙版；支持原生 3D 的壁纸可在“效果”中打开自定义资源，生成或导入素材，再用共用画板调整。保存素材后先确认预览，再点击系统“应用”更新锁屏。遇到问题时，从模块诊断页刷新并复制报告提交到 Issues。
