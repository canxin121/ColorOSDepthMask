# ColorOSDepthMask v0.1.12

修复景深只在预览生效、应用到实际锁屏后失效，以及部分壁纸开启原生 3D 后无效果的问题，并统一“蒙版”按钮与对应版本的原生“壁纸”按钮样式。

## 本次修复

- **保存后保留景深。** ColorOS 重新编码壁纸、生成新 URI 后，验证保存图片与当前壁纸相符，再关联已有蒙版，保留手动景深开关状态。
- **修复 3D 尺寸取整。** 接受原生 3D 网格缩放时的一像素取整差异，避免把同一张壁纸误判为比例不匹配，导致 3D 和景深一起失效；真正的素材错配仍会被拒绝。
- **统一蒙版按钮样式。** 沿用各版本原生背景、尺寸、间距和文字样式；新版工具栏复用其实际图标容器，显示原生圆形玻璃底与边缘高光。

验证范围与测试边界见 [v0.1.12 兼容性验证](https://github.com/canxin121/ColorOSDepthMask/blob/main/docs/compatibility-v0.1.12.md)。连接的 PJZ110 / ColorOS 17 / Wallpapers 17.04.0034 已完成按钮外观、点击和普通壁纸及 3D 效果复测；历史版本通过真实 APK 的自动回归，未逐台完成全部 ROM 的界面和 GPU 验收。
