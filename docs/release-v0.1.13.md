# ColorOSDepthMask v0.1.13

新增可编辑的自定义 3D 素材，重新设计蒙版、深度图与补全背景的共用画板，并修复双指缩放留下笔迹、自定义素材未被原生 3D 正确加载的问题。

## 本次更新

- **ColorOS 原生自动生成与素材编辑。** 在支持原生 3D 的壁纸上，调用系统自己的生成服务，随后编辑深度图、补全背景；继续支持手动导入。
- **修复自定义 3D 加载。** 处理原生资源缓存、算法版本与生成资源的复用，避免自定义图片已经保存却没有用于预览或后续应用。
- **统一通用画板。** 蒙版、深度图、背景共用画笔、橡皮、填充、直线、矩形、椭圆、吸管、图章和移动工具，保留完整分辨率及逐像素撤销 / 重做。蒙版与深度使用灰度选色，背景支持 HSV、色板和十六进制颜色。
- **修复多指编辑。** 第二根手指加入时取消整条未完成笔迹，双指缩放和平移不会画到图片上；填充和形状在操作完成后提交。
- **重新设计编辑界面。** 沿用 App 配色与组件风格，压缩顶栏和工具栏，让画布占据主要区域；适配横竖屏、小窗口、浅深色与大字号。
- **简化 3D 页面并自动更新预览。** 自动生成为简洁按钮，预览与深度设置直接显示；移除手动确认素材、重复载入及状态文字。保存素材修改后自动刷新预览，系统保存 / 应用壁纸时才更新实际锁屏。“预览内叠加壁纸透明度”仅用于编辑参考。

验证范围见 [v0.1.13 兼容性验证](https://github.com/canxin121/ColorOSDepthMask/blob/main/docs/compatibility-v0.1.13.md)。最终包通过 300 项本地 JVM / Robolectric 测试、Android 实际绘制与手势检查，以及多版本 Wallpapers 自动回归；已覆盖安装到 PJZ110 / ColorOS 17。自动回归不等同于所有 ColorOS 真机的联网生成、GPU 和锁屏视觉验收。

## 更新

通过 App“检查更新”下载安装，或下载下方 APK 覆盖安装。安装后在模块 App 中重载 Wallpapers；确认 LSPosed 已启用模块，作用域包含 `com.oplus.wallpapers`。

打开壁纸编辑页查看新画板和自定义 3D 资源，确认预览后再点击系统“应用”。已有锁屏需要重新应用壁纸，才能更新使用的素材。
