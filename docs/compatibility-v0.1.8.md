# ColorOSDepthMask v0.1.8 兼容性验证

版本：**0.1.8 / versionCode 47**。本次矩阵与真机安装使用同一份签名 release APK。

## 结论与范围

已完成 20 个真实 `com.oplus.wallpapers` 构建的兼容回归，其中 4 个原生同时具备
3D 壁纸编辑与景深能力的构建通过了本次新增 3D 适配验证。兼容选择检查完整的
类、构造器、字段和方法结构；16.05 的渲染器、协程和前景矩阵差异均单独适配。
16.05 没有新版景深动画回调，使用其本身的直接 surface 切换流程。

当前 PJZ110 上 `16.10.0082` 的预览、锁屏和手持晃动效果由用户测试并确认可用。
跨版本自动测试是在同一 Android 设备的独立 `app_process` 中加载各版本真实 APK，
执行其 Java 状态方法、Bitmap 操作和 3D 资源加载器，并直接加载最终 R8 APK。
它不等于在四套历史 ROM 上安装并操作全部厂商界面，也不等于逐版运行 native GPU
渲染器。未知版本、其它 ROM 和全部壁纸/锁屏模板的组合仍需对应环境验证。

## 本地与运动回归

本地 Robolectric **96 项测试通过，0 失败、0 错误、0 跳过**，包含真实图片素材。
覆盖异步加载与 surface 到达顺序、首次前景矩阵、景深开关、页面切换/重建、旧回调、
最新 revision、删除/反选、缓存损坏恢复、旧格式升级、人物表面归属及预览/保存一致性。

独立软件运动重放覆盖 **27 组平移和旋转**，参照为未修改的原生人物，而非含同一
自定义副本的背景。在 432×576 重放分辨率上，共比较 **2,450,030 次有效人物采样**，
超过 1 像素的参考位置偏差为 **0**，选中人物内部的缺失为 **0**。同一测试对先前
有问题的 3d.8 资源检出 **990,546 次**运动偏差，确认测试能检出已知回归。
完整用户 alpha 和嵌入的原始 ZIP 另有字节一致性断言。

软件重放使用原生人物绘制顺序、透视校正、CLAMP 采样和 alpha cutoff。
厂商资源包含超出当前层顶点范围的共用索引模板；重放记录并跳过不可寻址三角形，
不修改原始文件。运动结论限于受测素材和有效采样区域，不能替代 native GPU 的
软边缘与全部手持姿态验收。
